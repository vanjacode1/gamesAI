# AI Board Game Arena

**Play classic strategy games against AI, from simple tactics to full chess engine analysis.**

AI Board Game Arena is an interactive web app where users can play **Tic-Tac-Toe**, **Connect Four**, and **Chess** against AI opponents.  
The chess mode is powered by the **Stockfish engine**, allowing users not only to play against a strong chess AI, but also to analyze their moves, evaluate positions, and learn from their decisions.

## About This Project

I built this project to combine my interest in games, strategy, and AI.  
The goal was to create an interactive application that shows both technical implementation skills and attention to user experience.

## Games Included

### Tic-Tac-Toe

Play against an AI opponent that evaluates the board and chooses strategic moves.

### Connect Four

A larger strategy game where the AI considers board positions, threats, and winning opportunities.

### Chess

Play chess against the powerful **Stockfish chess engine**.

The chess module uses Stockfish to analyze positions and provide feedback after moves.

The engine can evaluate:

- Which side is better
- How strong or weak a move was
- The best available move in a position
- How the evaluation changes after each move

This turns the chess game into more than just a playable board, it becomes a learning tool.

While building this project, I improved my skills in:

- Building interactive web applications
- Designing API routes for game logic and AI move analysis
- Creating AI decision logic for classic board games
- Integrating the Stockfish chess engine
- Handling asynchronous engine responses
- Structuring game logic in a clean, reusable way
- Creating a user-friendly interface for real-time feedback
